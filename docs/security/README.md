# Security and Privacy

This directory records Stagenum's security, privacy, and data-governance
baseline before the product accepts real customer data.

- [MVP threat model, version 1](threat-model-v1.md) identifies protected assets,
  trust boundaries, abuse cases, mitigations, accepted risks, and owners.
- [MVP security, privacy, and data-retention baseline](mvp-security-privacy-baseline.md)
  defines minimum controls, record-class retention, incident response, and
  implementation acceptance criteria.

These documents are engineering decisions, not claims of certification or legal
advice. Material changes to identity, payments, evidence processing, native
clients, AI processing, or administrative access require a threat-model review.
